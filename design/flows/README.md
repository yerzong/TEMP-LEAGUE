# Flujos UX — Temp League

Flujos de usuario derivados de los docs de producto (`/docs`). Sirven de base para
wireframes y prototipos. **No inventar pasos fuera del alcance documentado.**

## Flujos prioritarios (app jugadores)
1. **Onboarding** — login social (Google/Apple/Xbox) o email → "Completa tu perfil"
   (teléfono + OTP, fecha nac., gamertag) → Home. *(gating para competir)*
2. **Crear org/equipo + inscribir** — crear organización (nombre/tag únicos) → crear roster
   → invitar (código/nickname, aceptar) → inscribir a evento.
3. **Seguir un evento** — ver bracket/tabla, calendario, mi próximo partido, avance.
4. **Día de partido** — check-in → (jugar) → ver resultado → avance/notificación.

## Flujos prioritarios (admin)
5. **Operar evento** — crear → abrir inscripciones → aprobar → generar (sorteo/round-robin)
   → proponer calendario → iniciar → capturar resultados → finalizar (campeón).
6. **Moderación** — revisar reporte → emitir/anular sanción.

> `/docs/12` (día de partido), `/docs/09` (reglas).
