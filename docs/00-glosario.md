# 00 · Glosario del dominio

Vocabulario común para todo el equipo y la documentación. Si un término aparece en el
código o en los docs, aquí está su definición canónica.

| Término | Definición |
|---------|------------|
| **Temp League** | La marca / plataforma. Organiza ligas y torneos de Gears en LATAM. |
| **Evento** | Cualquier competencia organizada en la plataforma. Es el concepto raíz. Puede ser una Temporada o un Relámpago. |
| **Temporada** | Evento largo (semanas). Fase regular (todos contra todos) + playoffs. Estilo LCK/LLA. Ej: "Temp League Temporada 1". |
| **Relámpago** ⚡ | Evento corto (1 día o fin de semana). Eliminación directa. Ej: "Copa E-Day Launch". |
| **Formato** | Reglas de cómo se compite dentro de un evento: `ROUND_ROBIN`, `SINGLE_ELIM`, `DOUBLE_ELIM`, `LEAGUE_PLAYOFFS`. |
| **Equipo** | Grupo de jugadores que compite unido. Tiene un capitán. |
| **Jugador** | Usuario que compite. Puede pertenecer a un equipo. |
| **Capitán** | Jugador con permisos para gestionar su equipo e inscribirlo a eventos. |
| **Admin** | Operador de Temp League. Gestiona eventos desde la consola web. |
| **Inscripción** | Registro de un equipo (o jugador) a un evento específico. Puede requerir aprobación. |
| **Roster** | Lista de jugadores de un equipo inscritos en un evento. |
| **Bracket** | Estructura de llaves de eliminación. Se genera automáticamente según el formato. |
| **Tabla de posiciones** | Clasificación de equipos en formatos de liga (round-robin). |
| **Partido (Match)** | Enfrentamiento entre dos equipos dentro de un evento. |
| **Jornada / Ronda** | Agrupación de partidos. "Jornada" en liga, "Ronda" en bracket. |
| **Seed** | Posición inicial de siembra de un equipo en un bracket. |
| **MVP** | (aquí) Producto Mínimo Viable — el alcance mínimo para correr la Temporada 1. |
