# 00 · Glosario del dominio

Vocabulario común para todo el equipo y la documentación. Si un término aparece en el
código o en los docs, aquí está su definición canónica.

| Término | Definición |
|---------|------------|
| **Temp League** | La marca / plataforma. Organiza ligas y torneos de Gears en LATAM. |
| **Organización (Org)** | Marca de esports registrada por un usuario. **Nombre y tag únicos.** Puede tener uno o varios equipos/rosters. Ej: "Zurco Esports". |
| **Equipo / Roster** | Alineación de jugadores dentro de una organización (ej. "Main", "Academy"). Es lo que se inscribe a un evento. |
| **Dueño (Owner)** | Usuario que crea y administra una organización. |
| **Capitán** | Jugador que lidera un equipo/roster; puede inscribirlo a eventos. |
| **Jugador** | Usuario que compite. Pertenece **a un solo equipo activo** a la vez. |
| **Staff / Caster** | Rol operativo. Transmite partidos y **captura resultados** desde el Admin Web. |
| **Admin** | Operador con control total de la liga desde el Admin Web. |
| **Evento** | Competencia organizada. Concepto raíz. Puede ser Temporada o Relámpago. |
| **Temporada** | Evento largo (semanas). Round-robin + playoffs. Estilo LCK/LLA. |
| **Relámpago** ⚡ | Evento corto (1 día / fin de semana). Eliminación directa. |
| **Formato** | Reglas de competencia: `SINGLE_ELIM`, `DOUBLE_ELIM`, `ROUND_ROBIN`, `LEAGUE_PLAYOFFS`. |
| **Inscripción** | Registro de un equipo/roster a un evento. Puede requerir aprobación y/o pago. |
| **Cuota de entrada** | Costo opcional por evento. Si el admin la activa, la inscripción se paga; si no, es gratis. |
| **Canal de transmisión** | Uno de los canales de streaming de la liga (Twitch/YouTube). Un partido se transmite en un canal. |
| **Bracket** | Estructura de llaves de eliminación. Se genera automáticamente. |
| **Tabla de posiciones** | Clasificación de equipos en formatos de liga (round-robin). |
| **Partido (Match)** | Enfrentamiento entre dos equipos dentro de un evento. |
| **Jornada / Ronda** | Agrupación de partidos. "Jornada" en liga, "Ronda" en bracket. |
| **Seed** | Posición inicial de siembra de un equipo en un bracket. |
| **Ventana de transferencia** | Bloqueo de **72 h** tras entrar/salir de un equipo, para evitar cambios abusivos de roster. |
| **OTP** | Código de un solo uso enviado por **SMS** para verificar el teléfono al registrarse. |
| **MVP** | Producto Mínimo Viable — alcance mínimo para correr la Temporada 1. |
